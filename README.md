**The auditor who codes the fix.**

Landing site for Nuada, a web accessibility auditing & remediation practice (RGAA/WCAG). Presents the audit offer and lets visitors request an audit — FR/EN/ES.

Live at [nuada-audit.netlify.app](https://nuada-audit.netlify.app).

## Stack

Astro, TypeScript, deployed on Netlify.

## Run

```bash
npm install
npm run dev      # localhost:4321
```
